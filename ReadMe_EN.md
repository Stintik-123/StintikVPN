**StintikVPN** is a collection of free VPN subscriptions. Copy a link → paste into a client → connect.

---

## How to use

1. Download a client for your device (table below).
2. Copy a link from **VPN subscriptions**.
3. In the client: Add subscription / Import from clipboard.
4. Refresh → Ping → pick a working server → connect.
