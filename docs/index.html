Гайды

Обход блокировок без VPN — раскрой нужный блок

Обход блокировок Discord и YouTube на Windows без полноценного VPN.

  1. Открой Flowseal/zapret-discord-youtube и скачай релиз из Releases.
  2. Распакуй архив и запусти service.bat.
  3. Нажми 11 → «Run Tests», отметь все .bat для проверки и tcp ping.
  4. После теста появится лучший .bat — запусти его из папки.
Открыть репозиторий →

Подбор параметров DPI-обхода под твою сеть.

  1. Скачай APK из ByeByeDPI.
  2. Установи и нажми «Подбор».
  3. Выбери строку с большим числом совпадений (59/60 лучше, чем 5/60) → «Применить».
  4. На главном экране нажми запуск.
Открыть репозиторий →

Локальный прокси для Telegram, когда MTProto отваливаются.

  1. Скачай сборку из Flowseal/tg-ws-proxy.
  2. Запусти tgwsproxy.exe.
  3. Следуй подсказкам в приложении и укажи прокси в настройках Telegram.
Открыть репозиторий →

Частые вопросы

Если что-то не завелось — сначала сюда

Подписки бесплатные, поэтому могут не работать в моменты большого наплыва людей. Попробуйте другие подписки или обновите текущую в клиенте.
Конфиги обновляются ежедневно их авторами. Ссылки на сайте всегда актуальны.
Это агрегатор других бесплатных VPN-подписок и прокси. Как создатель я ничего не трачу на серверы — просто собираю в одном месте всё бесплатное из интернета.
Прокси бесплатные, из-за чего их часто блокирует РКН. Список обновляется по мере возможности — если не работает, возьмите другой из раздела «Прокси».
Hiddify — самый простой вариант для Windows и Android. На iPhone / iPad — Streisand.
Конфиги из открытых источников и могут быть небезопасны. Не передавайте через них важные данные и не заходите в банки и другие критичные сервисы.

Важное предупреждение

Конфиги из открытых источников. Работоспособность не гарантируется. Запрещено использовать в противоправных целях.
