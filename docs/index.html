Обход без VPN (ByeDPI, zapret, tgwsproxy)

  1. Перейдите на страницу репозитория Zapret—discord—youtube и скачайте последний релиз из раздела Releases.
  2. Распакуйте архив и запустите файл service.bat
  3. Нажмите цифру 11 и выберите «Run Tests», затем выберите в меню .bat файл для проверки и tcp ping
  4. Проиходит тест, после чего появится надпись с лучшим bat файлом, зайдите в него для запуска
  1. Скачайте apk файл из репозитория ByeByeDPI.
  2. Установите приложение после чего нажмите подбор
  3. После завершения теста выберите текст с большим количеством совпадений (для примера 5/60 плохо, 59/60 хорошо) и нажмите на него и применить
  4. Вернитесь на главный экран и нажмите включить и выключить
  1. Скачайте сборку из репозитория Flowseal/tg-ws-proxy.
  2. Запустите файл tgwsproxy.exe
  3. Следуйте инструкциям внутри приложения
