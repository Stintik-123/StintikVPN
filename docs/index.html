Обход блокировок без VPN

  1. Перейдите на страницу репозитория Zapret-discord-youtube и скачайте релиз из раздела Releases.
  2. Распакуйте архив и запустите файл service.bat.
  3. Нажмите цифру 11 и выберите «Run Tests», затем отметьте в всех .bat файлах для прокси и tcp ping.
  4. Посмотрите тест, проверьте, после какого bat-файла открывается Discord/YouTube и заходите в него.
  1. Скачайте apk файл из репозитория ByeByeDPI.
  2. Установите приложение и нажмите «Подбор».
  3. Посмотрите тест в браузере с наибольшим числом совпадений (например, 5/60 — плохо, 59/60 — хорошо) и примените его.
  4. Вернитесь на главный экран и нажмите кноку запуска.
